# ノジョさんをさがせ！

散らかった部屋のどこかに隠れているクリスタルノジョさんを、一人称視点で探して集めるブラウザゲームです。

## ▶ [ここから遊べます](https://seibutu-h.github.io/nojo-seek/)

PC・スマホのブラウザで、そのまま遊べます（インストール不要）。スマホは横向きが遊びやすいです。

## 遊び方

1. つながった2つの部屋（こどもべや／リビング）に、10体ずつ、合計20体のノジョさんが隠れています。配置は毎回ランダムです
2. 部屋を歩きまわって、見つけたらクリック（タップ）で拾います。引き出し・とびら・おもちゃ箱のふたも開け閉めできます
3. クッションやぬいぐるみなど、1回だけ動かせるものもあります。ノジョさんは、その下や裏に隠れていることがあります
4. 最初に3つのお題が出ます。達成するとタイムが10秒ずつ（最大30秒）短くなります
5. 20体ぜんぶ見つけたらクリア。結果は X にポストできます（クリア結果の文と、ゲームの紹介カードで投稿されます）

操作は、PC が WASD ＋ マウス（Shift でダッシュ、右クリック長押しでズーム）、スマホが画面左右のスティックとタップです。

## おもな要素

- **お題**：毎回3つ。必ず達成できる配置のものだけが出ます。達成するとお題ずかんに記録されます
- **色違いノジョさん**：ときどき現れます。全100種で、見つけるとノジョずかんに載ります。ずかんでタップすると、拡大して回して眺められます
- **今日のチャレンジ**：その日だけの共通配置で、最短タイムを競います
- **ランキング**：最短クリアタイム／累計ゲット数／今日のチャレンジ。それぞれ PC・スマホ別にも見られます。ログインなしでも登録できます（ニックネーム未入力のときは「ななしのノジョ」）
- **Google ログイン（任意）**：ログインすると、記録・ずかん・お題の達成状況を別のブラウザや端末に引き継げます。ログインなしで貯めたランキングの記録も、ログイン時にまとめられます

## 技術スタック

| 分野 | 使っているもの |
|---|---|
| 3D描画 | [three.js](https://threejs.org/) r160（WebGL）。importmap で CDN（jsDelivr）から読み込み |
| 部屋と家具 | プログラムで生成。頂点カラーで色分けし、まとめて描画。角を少しだけ丸めた箱を自作 |
| 隠し場所のヒント | OutlinePass によるふち取りの光 |
| 配置 | シード付き乱数で生成。同じシードなら同じ配置になる（今日のチャレンジに利用） |
| モデル | 自作のクリスタルノジョ（glTF。ゲームに埋め込んで GLTFLoader で読み込み） |
| 色違い | モデルはそのままで、ガラス部分の材質の色や発光を差し替え（全100種） |
| 効果音 | Web Audio API でその場で合成（音声ファイルなし） |
| ログイン（任意） | Google Identity Services |
| ランキング・クラウド保存 | Google Apps Script（ウェブアプリ）＋ Google スプレッドシート。ログインなしの記録はブラウザごとの匿名IDで保存し、ログイン時に合体 |
| 保存 | localStorage（ニックネーム・記録・ずかん・設定） |
| 公開 | GitHub Pages |
| 共有 | X のポスト（intent）、OGP / Twitter Card |

## プライバシー

ランキングに記録を送ったときと、ログインしたときに、ニックネーム・プレイ記録と、本人を区別するための番号（ログインしていなければブラウザごとのランダムな匿名ID、ログインしていれば Google のユーザー識別番号）を保存します。メールアドレスや本名は読み取らず、保存もしません。詳しくは[プライバシーポリシー](https://seibutu-h.github.io/nojo-seek/privacy.html)をご覧ください。
