プライバシーポリシー

ノジョさんをさがせ！（非公式ファンメイドゲーム）／ 制定：2026年10月4日

「ノジョさんをさがせ！」（以下「本ゲーム」）は、富士葵さん・キクノジョーさんのファンが個人で制作した、非公式のゲームです。本ゲームにおける情報の取り扱いは、次のとおりです。

1. 取得する情報

ログインしなくても遊べます。「Googleでログイン」を使った場合のみ、次の情報をランキングとクラウド保存のために保存します。

  • ニックネーム（ご自身で入力したもの）
  • クリアタイム、見つけた数、お題の達成状況、ずかんの記録などのプレイ記録
  • Google が発行するユーザー識別番号（ログインしたご本人を区別するための番号）

メールアドレス、本名、Google アカウントのプロフィール画像などは、保存しません。

2. 利用目的

ランキングの表示、記録のクラウド保存（別の端末での引き継ぎ）、ゲームの改善のためにのみ利用します。広告には利用しません。

3. 保存場所と第三者提供

情報は、制作者が管理する Google スプレッドシート（Google Apps Script 経由）に保存します。法令に基づく場合を除き、第三者に提供しません。ランキングには、ニックネームと記録が他のプレイヤーにも表示されます。個人が特定される情報はニックネームに入れないでください。

4. 端末内に保存される情報

ブラウザの保存領域（localStorage）に、ニックネーム、プレイ記録、設定を保存します。ブラウザのデータを消すと削除されます。

5. 外部サービス

ログインに Google Identity Services を、3D 表示に three.js（MIT License）を、ホスティングに GitHub Pages を利用しています。これらのサービスは、それぞれの提供元のポリシーに従って情報を取り扱う場合があります。

6. 削除のご依頼

ランキングやクラウド保存の記録の削除を希望される場合は、下記の連絡先までご連絡ください。ご本人のものと確認できる範囲で、対応します。

7. 改定

必要に応じて本ポリシーを改定します。改定後は、このページに掲載します。

連絡先

GitHub リポジトリの Issues からご連絡ください。
